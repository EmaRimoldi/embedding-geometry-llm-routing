# Executed validation

This directory records checks actually run when the repository was prepared. Synthetic checks execute the recovered kNN and soft-prior implementations; full-panel reference controls recompute training-selected single-model and realized-oracle scores on the available historical cohorts.

These are not final October experiment reproductions. Embeddings and benchmark text are not included. See `run-summary.json` for environment versions and run counts, and the reference JSON files for input hashes and numerical controls.
